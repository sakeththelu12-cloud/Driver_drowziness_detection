# Driver_drowziness_detection
Driver Drowsiness Detection (TensorFlow.js) Real-time driver drowsiness detection powered by a fine‑tuned EfficientNetV2‑S CNN, trained in Python/TensorFlow and deployed entirely client‑side with TensorFlow.js. The app runs directly in the browser using the driver’s webcam — no backend server, no API costs, and fully hostable on GitHub Pages.
